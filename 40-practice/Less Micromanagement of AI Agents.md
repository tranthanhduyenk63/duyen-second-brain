# Less Micromanagement of AI Agents

## Context
Using Claude as a coding agent on [[LMS Platform]].

## Problem
I micromanaged the agent sessions, which meant I had to load and keep a lot of context in my own head.

## What I did
Stopped managing the sessions so closely. TODO(ask): what does "less" look like now? E.g. give the goal and constraints and let it plan, review only the final diff, or let it run tests itself.

## Result
- It worked better and faster.
- I don't need to load as much context myself ([[Cognitive Load]]).

## Lessons
- Over-directing an agent costs me more [[Cognitive Load]] and gets worse results. Give it the goal and let it work.
- TODO(ask): does this depend on the codebase being in good shape ([[Agent-Friendly Codebase]])?
